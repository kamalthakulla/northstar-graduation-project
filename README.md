# Northstar Graduation Project
 
## Overview
 
Northstar is a smart supermarket mobile application developed as a final-year Computer Science project.
 
The application is designed to improve the shopping experience by allowing users to browse products, manage shopping activities and access supermarket services through a mobile platform.
 
## Objectives
 
- Develop a user-friendly Android application
- Improve customer shopping experience
- Provide product browsing functionality
- Implement secure user authentication
- Demonstrate software engineering principles
 
## Features
 
- User Registration and Login
- Product Catalogue
- Product Search
- Shopping Cart
- User Profile Management
- Responsive Mobile Interface
 
## Technologies Used
 
- Kotlin
- Android Studio
- Firebase
- MongoDB
- GitHub
 
## Development Methodology
 
- Requirements Analysis
- System Design
- Application Development
- Testing and Evaluation
